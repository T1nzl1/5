# Практическая работа 5 — оценка 4

## Запуск

Терминал 1:

```powershell
node mock-server.js --port 8080 --origin http://localhost:5555
```

Терминал 2:

```powershell
flutter pub get
flutter run -d chrome --web-port=5555
```

## Тестовые аккаунты

- reader / Reader1! — Анна Читатель
- librarian / Librarian1! — Иван Библиотекарь
- admin / Admin1! — Ольга Администратор

## Роли

### Читатель
- каталог книг и карточка книги;
- экран «Мои выдачи»;
- видит только свои выдачи;
- может продлить активную выдачу на 14 дней;
- не видит кнопки изменения каталога.

### Библиотекарь
- управление книгами и справочниками;
- работа с читателями;
- экран «Выдачи»;
- оформление выдачи: читатель + книга + срок;
- закрытие/возврат выдачи;
- при выдаче книги без свободных экземпляров сервер возвращает 409.

### Администратор
- отдельный экран «Админ»;
- статистика;
- пользователи и смена ролей;
- восстановление мягко удалённых записей;
- физическое удаление.

Роли специально не построены как «админ умеет всё библиотекаря»: у каждой роли свой набор функций и свой закрытый экран.

## Защита маршрутов и 403

Попробуйте читателем вручную открыть:

`http://localhost:5555/admin/users`

или

`http://localhost:5555/books/new`

Клиент отправит на экран «Доступ запрещён». На этом экране есть кнопка «Проверить защиту сервера (403)»: она делает реальный запрос к административному API, сервер возвращает 403, а приложение показывает понятное сообщение.

## Связь пользователя и читателя

Аккаунт `reader` связан с записью `Анна Читатель` через `readerId=1`. Поэтому библиотекарь может оформить выдачу на Анну, а после входа под `reader` эта же выдача появится в «Мои выдачи».

При регистрации нового пользователя автоматически создаётся соответствующая запись читателя и читательский билет.

## Хранение данных mock-server

После первого запуска рядом с `mock-server.js` создаётся `mock-data.json`. Книги, читатели, пользователи, роли и выдачи сохраняются туда, поэтому обычный перезапуск сервера больше не стирает созданные записи. Для возврата к начальному набору данных остановите сервер и удалите `mock-data.json`.
